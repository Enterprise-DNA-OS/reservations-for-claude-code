# Weekly review
Run `npm run reservations -- covers-forecast --json`, `npm run reservations -- attention --json` and `npm run reservations -- no-shows --json`. Then run `compliance --json` through the same CLI. Summarise expected covers, missing seating, enquiries, repeat no-shows, kitchen handovers and retention reviews. Name each reference requiring a decision. Do not invent bookings or send reminders.
